# 🎙️ ¿Y si mi voz pudiera hablar sin mí?

Proyecto de clonación de voz con **Python y Chatterbox Multilingual**

El objetivo era comprobar si, con solo **15 segundos de mi voz**, una IA podía generar frases que nunca había pronunciado, incluso en otros idiomas.

## 🛠️ Tecnologías utilizadas

Python · PyTorch · Chatterbox Multilingual · Librosa · Jupyter Notebook
